# GitHub Actions

Inspect reusable workflows/actions and repository conventions before adding another pipeline.

Use least-privilege permissions, pin important external actions according to repo policy, keep secrets out of logs, and make cache keys explicit.

When debugging, inspect the failing job/step and event context rather than repeatedly editing YAML. Validate with actionlint when available.
