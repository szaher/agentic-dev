# Container Development

Understand the build context, base image, multi-stage flow, user, filesystem, network/ports, health checks, and runtime configuration.

Keep images reproducible and minimal without hiding required debugging/runtime dependencies. Avoid embedding secrets.

Use the repository's Docker/Podman/Compose workflow and verify the resulting runtime behavior, not only a successful image build.
