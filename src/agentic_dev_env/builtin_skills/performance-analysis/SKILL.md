# Performance Analysis

Establish a baseline and representative workload before optimizing. Identify the bottleneck with profiling/metrics rather than guessing.

Change one meaningful factor at a time. Measure CPU, memory, I/O, latency/throughput, allocation, or external dependency time as appropriate.

Preserve correctness tests and add a reproducible benchmark or measurement when the repository supports it.
