# TypeScript Engineering

Read `package.json`, lockfile, tsconfig, framework conventions, and nearby tests before editing.

Use the detected package manager. Preserve strict typing; avoid `any` and unsafe casts unless justified by an external boundary.

Use existing package scripts for format, lint, typecheck, test, and build.
